A bit about how I work

I'm completing a Bachelor of Science in Biomedical Engineering Technology at Foundation University School of Science and Technology (expected 2027). My core interest is in combining computational methods — machine learning, signal processing — with hands-on systems work — sensors, embedded controllers — to build tools that help detect neurological conditions earlier and more objectively.

My flagship work right now is an AI-based system for early Alzheimer's detection using speech patterns and cognitive assessment data, currently under review at IEEE JBHI. I've also built several hands-on biomedical devices from the ground up, and I'm partway through an applied ML internship testing SEO assumptions against real performance data — a different domain, but the same underlying skill of asking whether a common assumption actually holds up when you check it.
