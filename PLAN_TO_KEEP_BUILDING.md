# The Plan to Keep Building

## 1. How to add the next case study

New case studies go on `projects.html` (hands-on/applied work) or `research.html`
(research-track work), depending on type — both use the same repeatable structure.

**Steps to add one:**
1. Add a new `<div class="field-block">` section, following the three-beat shape from
   Week 2: **Problem** (what wasn't working / what question I had), **What I did** (the
   actual build/method, one paragraph), **What came of it** (result, honestly stated —
   including limitations if the work isn't finished).
2. If there's a visual (chart, photo, screenshot), add a `<figure class="proof-image">`
   block right after the text, same pattern as the existing project cards.
3. Update the homepage (`index.html`) lede if the new work changes my one-line summary of
   what I do.
4. Re-check SEO meta tags (`og:description`) on the relevant page if the new work is
   significant enough to change how the page should be described when shared.
5. Commit, then re-verify the live site (favicon, share preview, mobile) exactly like the
   Week 7 launch-hygiene pass — a 5-minute check, not a full redo.
